Methodology

What We Are

Global Pulse is an anonymous binary (support / oppose) public sentiment reference site. It is not a scientific sample poll or an official election.

Voting Rules

No registration required. Each IP counts as one vote per leader. You may change your vote at any time; the latest choice counts. Abnormal traffic enters a verification pool and is temporarily excluded from public rankings.

Ranking Algorithm

Approval rate = support votes / (support + oppose). Rankings use Wilson confidence correction to reduce extreme values from small samples. The global leaderboard requires ≥ 1,000 valid votes in the last 30 days.

Map Data

The world map shows country-level aggregated approval only. It does not display city or individual-level data.
